# Radmin VPN для Steam Deck — тестовая версия 0.1.6

В 0.1.6 добавлен переключатель **«Запуск с окном Radmin»** для сравнительного теста.
Установите новый ZIP, затем нажмите **«Установить компоненты VPN»**, чтобы обновить
системную часть до 0.1.6. Уже скачанная среда Wine используется повторно.
При выключенном VPN включите **«Запуск с окном Radmin»**, затем включите VPN.
Будет использован обычный запуск upstream без `--no-ui`, прямо в игровом режиме.
Окно может появиться поверх Steam. **Закрытие окна останавливает VPN**; для игры
переключайтесь обратно в Steam, сохраняя Radmin открытым. Автоматическое скрытие
окна не реализовано: сначала требуется проверить, меняет ли наличие GUI подключение.
Этот режим — проверяемая гипотеза, работа связи с ПК ещё не подтверждена.

Кнопка в Decky Loader для запуска настроенного Radmin VPN в игровом режиме.
Есть включение/выключение, VPN IP, перезапуск и журнал. Приложение Radmin
работает от пользователя `deck`; ограниченный системный обработчик настраивает
только VPN-адаптер. Пароль в плагине не хранится.

Локально проверены сборка интерфейса, логика, синтаксис и реальная релизная AppImage.
На устройстве подтверждены запуск службы, создание адаптера и маршрутов.
Связь с участниками сети в игровом режиме пока не подтверждена.
Нужен Steam Deck x86_64 со SteamOS, пользователем `deck` и установленным Decky Loader.
Поддержка Bazzite, других пользователей и других устройств пока не заявляется.

## Установка на Steam Deck

### Через ZIP в игровом режиме Decky (рекомендуется для теста)

1. Скопируйте **`Radmin-VPN-0.1.6-Decky.zip`** на Steam Deck. Не распаковывайте.
2. В игровом режиме откройте Decky → настройки → режим разработчика → установка
   плагина из ZIP и выберите этот файл. Название пункта может зависеть от версии Decky.
3. Откройте **Radmin VPN** в списке плагинов и нажмите **«Установить компоненты VPN»**.
   Decky запустит системный установщик; пароль вводить не нужно.
4. Дождитесь завершения загрузки (~178 МБ) и установки. Ход установки доступен
   через **«Показать журнал»**. Статус обновляется автоматически.
5. Если Radmin уже настроен через исходную AppImage, включите переключатель VPN.
   Если префикса ещё нет или нужно добавить сеть, потребуется один раз настроить
   её через ярлык на рабочем столе, как описано ниже.

В версии 0.1.1 ZIP содержит системные обработчики и установщик. ZIP 0.1.0 с
пометкой Decky-only содержал только интерфейс и требовал отдельной установки
через терминал. Для нового теста используйте 0.1.6: исправлены конфликты запуска,
настройка запуска без пароля и доступ пользователя deck к среде Wine.
Подробности — `CHECK_REPORT.md`.

При обновлении с предыдущих версий установите новый ZIP поверх старого в Decky, затем нажмите
«Установить компоненты VPN». Существующая среда Wine используется повторно.
Установщик добавляет в конец `/etc/sudoers` управляемое подключение только правила
Radmin, чтобы более поздние системные правила не требовали пароль для обработчика.
Конфигурация проверяется `visudo` до замены, исходный файл сохраняется в
`/etc/radmin-decky/sudoers.before-radmin-decky`. Полное удаление убирает только
добавленный блок, сохраняя остальные правила.

### Через терминал на рабочем столе (альтернативный способ)

1. Перейдите в режим рабочего стола. Закройте обычный Radmin, если он запущен.
2. Скопируйте архив `Radmin-Decky-0.1.6-SteamDeck.zip` на Deck и распакуйте.
3. Откройте папку `Radmin-Decky-0.1.6` в Dolphin. Правой кнопкой по свободному
   месту → «Открыть терминал здесь». Выполните:

   ```bash
   bash ./install.sh
   ```

4. Дождитесь загрузки среды (~178 MiB). Введите пароль пользователя `deck`
   при установке системной части. Если пароль ещё не задан, сначала задайте
   его командой `passwd`. Это пароль SteamOS, а не пароль сети Radmin.
5. Перезагрузите Steam Deck: Decky подхватит установленный плагин.

Установщик не отключает защиту системного раздела SteamOS и не использует pacman.
Он добавляет службу в `/etc/systemd/system`, обработчики в `/etc/radmin-decky`,
ограниченное правило `/etc/sudoers.d/radmin-decky` и плагин в
`/home/deck/homebrew/plugins/Radmin VPN`.
Исходная AppImage проверяется по закреплённому SHA-256, затем распаковывается;
для запуска не требуется FUSE. Среда Wine находится в
`/home/deck/homebrew/data/radmin-decky-runtime`.
Нужно свободное место для скачивания, распаковки и резервной копии префикса;
рекомендуется хотя бы 3 ГБ, больше при большом существующем префиксе.

## Первичная настройка сетей

Если Radmin уже установлен через AppImage из исходного проекта, используются
его настройки из `/home/deck/.local/share/radmin-vpn-linux/wineprefix`.
При первой установке плагина существующий префикс копируется в
`/home/deck/.local/share/radmin-decky-backups/`; исходник не удаляется.
Установка из исходников с префиксом в другой папке автоматически не переносится.

На рабочем столе появится ярлык **«Настроить Radmin VPN»**. Откройте его один
раз, проверьте свои сети и при необходимости присоединитесь к ним.
При первом запуске Windows-приложение загрузится с сайта Famatech и установится
в этот префикс — это может занять несколько минут.
Убедитесь, что внутренняя кнопка питания Radmin включена. Отключите автоматическое
обновление Radmin в его настройках. Закройте окно Radmin обычным крестиком.

Перед открытием этого ярлыка выключайте VPN переключателем Decky.
Одновременный запуск ярлыка, службы и обычной AppImage блокируется.
Добавление новых сетей и список друзей внутри Decky в эту версию не входят.

## Обычное использование

Игровой режим → кнопка **…** → **Decky** → **Radmin VPN** → включить переключатель.
Дождитесь сообщения **«VPN запущен, адаптер и маршрут готовы»** и адреса `26.x.x.x`.
Затем запускайте игру. При необходимости подключайтесь к IP друга вручную.
Индикатор означает готовность локального VPN, доступность друга проверяется отдельно.

Переключатель выключения останавливает VPN и удаляет его адаптер, маршруты и
добавленные правила брандмауэра. Закрытие панели Decky не выключает VPN.
После перезагрузки VPN выключен; автозапуск в этой сборке отключён.
Перезапуск Decky не прерывает VPN; удаление плагина через Decky останавливает
службу, но системную часть нужно удалить командой ниже.

Пока VPN работает, маршруты `26.0.0.0/8`, широковещательных и multicast-пакетов
направляются в его адаптер: это нужно некоторым LAN-играм. Другой VPN может
конфликтовать с этими маршрутами. Такое поведение унаследовано от исходного проекта.

## Что проверить при первом тесте

1. Плагин появился в Decky после перезагрузки.
2. Включение в игровом режиме проходит без запроса пароля, появляется VPN IP.
3. Друг видит Deck в Radmin; соединение работает в обе стороны.
4. Игра подключается к другу по VPN IP. Если поиск LAN-сервера не работает,
   сначала проверьте прямое подключение к IP.
5. Выключение и повторное включение работают без ошибок.
6. После сна и пробуждения проверьте связь. Если пропала — нажмите «Перезапустить VPN».
   Автоматическое восстановление после сна в этой сборке не реализовано.

Если запуск не удался, откройте **«Показать журнал»** в плагине. Для получения
журнала в терминале:

```bash
sudo journalctl -u radmin-decky.service -b -n 150 --no-pager
```

Журнал последнего запуска также находится в
`/home/deck/.local/share/radmin-vpn-linux/run.log`, предыдущего — `run.previous.log`.
Перед передачей журнала можно скрыть свои сетевые имена и IP.
Если написано «Radmin already running», закройте обычную AppImage/окно настройки.
Если зависло «Запускается», особенно после перехода между режимами SteamOS,
нужен журнал: среда графической сессии Wine ещё требует проверки на устройстве.

## Полное удаление

На рабочем столе выполните:

```bash
sudo bash /etc/radmin-decky/uninstall.sh
```

Затем перезагрузите Deck. Настройки Radmin, его ID, префикс и резервные копии
сохраняются. Обычную AppImage можно снова использовать.

## Разработка

Исходники включены. `pnpm install`, `pnpm typecheck`, `pnpm build`.
Python-тесты: `python -m unittest discover -s tests -v`.
Проверка собранного интерфейса на имитации Decky: `node tests/frontend-smoke.mjs`.
Для `scripts/verify_syntax.py` нужен Bash; на Windows задайте путь в `BASH_CHECK`.
Упаковка: `python scripts/package_release.py`.
Зависимости закреплены в `pnpm-lock.yaml`.

Исходный проект: https://github.com/baptisterajaut/radmin-vpn-linux
Используется выпуск v1.1.1; SHA-256 AppImage:
`14601f601c171ac4ad855e9a9e69473ae5ebf62503ce5271c6a38d3ac475f2f3`.
Детали лицензирования: `THIRD_PARTY.md`.


## Building and publishing updates

Run `pnpm install --frozen-lockfile`, `pnpm typecheck`, and `pnpm build` from this repository.
Run `python -m unittest discover -s tests` and `node tests/frontend-smoke.mjs` to check the backend and built frontend.
For a new version, update `package.json` and `scripts/package_release.py`. If system components changed, also update the system version in `main.py` and `scripts/install-root.sh`.
Run `python scripts/package_release.py` and `python scripts/verify_release.py`. Tag the tested commit and attach the Decky ZIP and its SHA-256 checksum to the corresponding GitHub release.
